## 公共发布与宿主边界

本仓库独立管理版本、构建器、测试和发布制品。通过 GitHub Release 固定版本发布，再由 ViTalk 公共目录审核收录。当前功能包格式为 `vitalk-feature/v1`，必须与支持它的宿主受信定义一致，不能仅修改 ID 来获得原生能力。

本项目提供安装定义与构建器；原来的完整页面、录音、数据库及业务流程仍由 ViTalk 宿主实现。这不是一个包含全部原生源码的通用第三方页面插件。宿主升级前提与包版本分开管理。

公共目录使用 catalog-v2.json；1.0.0 最低宿主 ViTalk 0.6.12，1.0.1 最低宿主 ViTalk 0.6.13。该版本源码已支持新的市场流程，应用二进制发布需单独完成，旧版不能因安装包而自动增加原生功能。

## 1.0.1
